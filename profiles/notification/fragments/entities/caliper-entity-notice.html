A Caliper Notice entity represents a notable remark or alert that a user, or system, sends to another user to draw their attention to an important matter.

A Notice consists of the data of a notable remark to send; it can be dispatched to more than one user. When dispatched to a user, it must be contained within a Notification" envelope.

IRI
http://purl.imsglobal.org/caliper/Notice
Term
Notice
Supertype
Entity
Properties
Notice inherits all properties defined by its supertype Entity, of which id and type are required. Additional type restrictions are described below:
Property Type Description Disposition
type Term The string value MUST be set to the Term Notice. Required
body string The plain-text content of the notice. Required
creators Array An ordered collection of Agent entities that created this notice. Each array item MUST be expressed either as an object or as a string corresponding to the object's IRI. Optional
isPartOf ResearchContext | IRI The ResearchContext describing the experimental condition or intervention that comprises this notification. The isPartOf value MUST be expressed either as an object or as a string corresponding to the object's IRI. Optional
name string The plain-text content of the notice's subject. Optional
