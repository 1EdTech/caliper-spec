A Caliper Notification entity represents a Notice prepared for delivery to a recipient by a user or system.

A Notification consists of the Notice data sent, the sender and recipient for the notification, the medium used to send the notification, and the time of creation and sending.

IRI
http://purl.imsglobal.org/caliper/Notification
Term
Notification
Supertype
Entity
Properties
Notification inherits all properties defined by its supertype Entity, of which id and type are required. Additional type restrictions are described below:
Property Type Description Disposition
type Term The string value MUST be set to the Term Notification. Required
dateSent string An ISO 8601 date and time value expressed with millisecond precision that describes when the Notification was sent to the recipient. The value MUST be expressed using the format YYYY-MM-DDTHH:mm:ss.SSSZ set to UTC with no offset specified. Required
notice Notice | IRI The Notice containing the actual content of the notification sent to the recipient. The notice value MUST be expressed either as an object or as a string corresponding to the object's IRI. Required
recipient Person | IRI The Person to receive the notification. The recipient value MUST be expressed either as an object or as a string corresponding to the object's IRI. Required
medium string A string value comprising a word or phrase identifying the medium used to send the notification (for example, "Email" or "SMS"). Optional
sender Agent | IRI The Agent identified as the sender of the notification. The sender value MUST be expressed either as an object or as a string corresponding to the object's IRI. Optional
