A Caliper NotificationEvent models the act of sending a notice to a user to notify them of some important circumstance worthy of their attention.

IRI
https://purl.imsglobal.org/caliper/NotificationEvent
Term
NotificationEvent
Supertype
Event
Properties
The NotificationEvent inherits all properties defined by its supertype Event, of which id, type, actor, action, object, and eventTime are required. Profile-specific type restrictions are described below:
Property Type Description Disposition
type Term The string value MUST be set to the Term NotificationEvent. Required
actor Agent |Person | IRI The Agent or Person that initiated the action. If the action is Notified then the actor value MUST be expressed as an Agent. If the action is Viewed or Dismissed then the actor value MUST be expressed as a Person. The actor value MUST be expressed either as an object or as a string corresponding to the object’s IRI. Required
action Term The action or predicate that binds the actor or subject to the object. The value range is limited to the Notified, Viewed, and Dismissed actions only. Required
object Person | Notification | IRI The Person or Notification that is the object of the action. If the action is Notified then the object value MUST be expressed as a Person. If the action is Viewed or Dismissed then the object value MUST be expressed as a Notification. The object value MUST be expressed either as an object or as a string corresponding to the object’s IRI. Required
generated Notification | IRI The Notification sent to the recipient. The generated value MUST be expressed either as an object or as a string corresponding to the object’s IRI. Required (Notified action only)
